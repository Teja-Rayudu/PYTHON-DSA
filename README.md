# 🐍 Data Structures and Algorithms in Python

Explore fundamental data structures and algorithms in Python—essential for cracking coding interviews and building efficient backend systems.

---

## _🌐 Breadth First Search (BFS)_
> Traverses a graph or tree level by level. Commonly used to find the shortest path in unweighted graphs.
![BFS Traversal](https://upload.wikimedia.org/wikipedia/commons/5/5d/Breadth-First-Search-Algorithm.gif)

---

## _🌲 Binary Tree_
> A hierarchical data structure where each node has at most two children: left and right.
![Binary Tree](https://upload.wikimedia.org/wikipedia/commons/thumb/5/5e/Binary_tree_v2.svg/500px-Binary_tree_v2.svg.png)

---

## _🔍 Binary Search Tree (BST)_
> A binary tree with nodes ordered: left < root < right. Provides fast search, insertion, and deletion.
![Binary Search Tree](https://upload.wikimedia.org/wikipedia/commons/d/da/Binary_search_tree.svg)

---

## _🫧 Bubble Sort_
> Simple sorting algorithm that repeatedly compares and swaps adjacent elements if they are in the wrong order.
![Bubble Sort](https://upload.wikimedia.org/wikipedia/commons/3/37/Bubble_sort_animation.gif)

---

## _🕸️ Graph_
> A set of nodes (vertices) connected by edges. Represents networks, relationships, and connections.
![Graph Example](https://upload.wikimedia.org/wikipedia/commons/5/5b/6n-graf.svg)

---

## _#️⃣ Hashing_
> Converts data to a fixed-size hash for quick lookups in hash tables.
![Hash Table](https://upload.wikimedia.org/wikipedia/commons/thumb/7/7d/Hash_table_3_1_1_0_1_0_0_SP.svg/1200px-Hash_table_3_1_1_0_1_0_0_SP.svg.png)

---

## _🔗 Linked List_
> Linear data structure with nodes pointing to the next node; efficient for dynamic memory allocation.
![Linked List](https://upload.wikimedia.org/wikipedia/commons/6/6d/Singly-linked-list.svg)

---

## _🧵 Multithreading_
> Runs multiple threads concurrently, improving performance and responsiveness in programs.
![Multithreading Concept](https://upload.wikimedia.org/wikipedia/commons/thumb/a/a5/Multithreaded_process.svg/375px-Multithreaded_process.svg.png)

---

## _📚 Queue_
> Linear structure following FIFO (First-In, First-Out); used in scheduling and buffering operations.
![Queue](https://upload.wikimedia.org/wikipedia/commons/5/52/Data_Queue.svg)
